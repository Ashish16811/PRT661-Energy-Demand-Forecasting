# Stage 2 Readiness Contract

A regional modelling dataset should not enter Stage 3 until the required
preprocessing and validation checks pass.

Readiness covers:

- valid 30-minute grid
- chronological timestamps
- no duplicated timestamps
- expected training boundary
- target availability
- feature schema
- holiday integration
- weather provenance
- future feature safety
- regional metadata

Validation should remain independent of model selection.
